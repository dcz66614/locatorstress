## 一、项目是什么

浏览器自动化定位器确定性 DOM 变异压力实验室。UI 改版前，自动对定位器（CSS / XPath / role）做 8 种确定性 DOM 变异（M01–M08：包裹插入、同级重排、类名变更、重名插入、嵌套 iframe、Shadow DOM、隐藏副本、文本变更），用真实本地 Playwright 执行定位器，判定四态 verdict（STABLE / WRONG_TARGET / AMBIGUOUS / MISSING），给出稳定性分数与最短失败变异序列（有界 BFS ≤6 步），输出本地 Web UI + JSON 导出 + HTML 报告。

- 不是定位器生成器，不做浏览器兼容认证；100% 合成数据，固定 seed；无真网、无真人、无 GPU、无付费 API、无 LLM 调用。
- 技术栈：TypeScript + Node + Playwright（本地 Chromium）+ 独立 Python Oracle（预埋目标标识，定位器不可见）。
- 零真人参与（全程合成数据 + 确定性算法 + 独立 Oracle + 自动化断言）。
