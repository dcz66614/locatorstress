Locator 编辑

先在 Fixture Lab 选择一个 fixture，这里载入它的冻结 Locator 供编辑与校验。

内置模式下，分析使用所选 fixture 的冻结 Locator；自定义输入模式下，分析使用本页编辑的合成 HTML、LocatorSpec 与私有目标描述（目标描述只供 Oracle 定位原目标，不会暴露给被测 Locator）。本页只做两件事：① 用后端 /api/validate 校验编辑后的 LocatorSpec 或自定义场景语法；② 在浏览器内预览它在原始 DOM 上的匹配情况（匹配计数与是否命中同一元素，仅为预览，不计算 verdict）。空必填字段等格式问题先由格式检查拦下（不发送给后端）；通过格式检查的草稿一律发给后端校验。本工具不提供自动生成、推荐或修复 Locator 的功能。

目标描述必须在你的 HTML 上恰好命中一个元素；命中 0 个或多个时分析拒绝运行（422），不会悄悄改用 fixture 定位器。

Mutation Lab — M01–M08 与 DOM diff

变异后 DOM 来自 UI 服务器：它在独立 Playwright 页面上用冻结的变异注册表真实执行算子并序列化 DOM（含 open ShadowRoot 内容），只作展示，不参与 verdict 计算。选择一个算子查看原始 DOM 与变异 DOM 的行级差异。

Verdict Matrix — 四态结果

点击「运行分析」后，后端在真实 Chromium 上跑 baseline + M01–M08（共 9 次执行），返回四态 verdict。内置模式分析所选 fixture；自定义输入模式分析你在 Locator 编辑页输入的场景。WRONG_TARGET 表示“返回了一个元素，但不是原目标”。颜色不是唯一的状态通道：每个格子都写明 verdict 文字。

BFS Witness — 最短失败序列

有界 BFS（深度 ≤ 6，状态 ≤ 4096）在后端运行；首个非 STABLE 序列即最短失败见证。BOUNDED_NO_WITNESS 只表示有限搜索内未找到，不证明所有 DOM 变化都安全；BOUNDED_INCOMPLETE 表示预算耗尽、搜索未完成，绝不是“无见证”。

Report — 稳定性分数与导出

分数 = 100 × STABLE 用例数 / 已完成用例数（合成变异集比例，不是生产失败概率）；incomplete 用例不计分但降低 coverage。分数与控制组指标由 UI 服务器调用冻结的 T005 计分模块算出，浏览器只展示。
